!!! tip "Have a vulnerability to report?"

    Vultron is a protocol, not a place to send a report.
    Report it to the vendor through its security contact, which is often published in a [`security.txt`](https://securitytxt.org/){:target="_blank"} file on its website.
    If you cannot reach the vendor, or it does not respond, the CERT Coordination Center (CERT/CC) can coordinate the case: [report it to CERT/CC](https://kb.cert.org/vuls/report/){:target="_blank"}.
    The [CERT Guide to Coordinated Vulnerability Disclosure](https://certcc.github.io/CERT-Guide-to-CVD){:target="_blank"} explains what to expect along the way.
