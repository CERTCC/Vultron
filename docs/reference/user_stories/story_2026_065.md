# User Story `2026_065`

<!-- story-start -->As a Participant, I want a role in a case to change hands only through an offer that the Case Owner makes by way of the CASE_MANAGER and that the target accepts, with both recorded in the case ledger, so that every participant knows who holds which role and nobody grants a role to itself<!-- story-end -->

## Notes

Roles decide what each Participant may do in a case.
The CASE_MANAGER checks each offer, records it, forwards it to the target and grants the role only when it records the acceptance.
An offer that it refuses leaves no record and reaches nobody, and a refusal changes no role.
