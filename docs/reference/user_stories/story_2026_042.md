# User Story `2026_042`

<!-- story-start -->As a Participant, I want the CASE_MANAGER's own progress on a case recorded the way every participant's is, so that I can tell from the case record whether the case is being evaluated, is being coordinated or is closed<!-- story-end -->

## Notes

The CASE_MANAGER holds a participant record in the case like any other party.
Its report management state says how far case creation has got and whether the Case Owner has left.
Each of its transitions is a ledger entry, so other Participants learn it the same way they learn anyone else's.
