# User Story `2026_062`

<!-- story-start -->As a Peer Implementer, I want every case-scoped message to arrive at the participant's one inbox and to name its case in `context`, so that my peer files each message under the right case without a separate address for each case<!-- story-end -->

## Notes

An actor takes part in many cases behind one identity.
A separate inbox for each case would be a second address that senders must discover and trust, and a message sent to the wrong one would not reach the case.
One standard field for the case lets every receiver find the right copy the same way.
