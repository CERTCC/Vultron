# User Story `2026_017`

<!-- story-start -->As a Node Operator, I want malformed, oversized or undecryptable requests to be refused with specified HTTP statuses and structured error bodies, so that clients can diagnose faults without my help<!-- story-end -->

## Notes

An operator otherwise answers every client fault by reading server logs.
A stated status and error body lets the client see what it sent wrong.
