# User Story `2026_013`

<!-- story-start -->As a Peer Implementer, I want an unrecognized or malformed activity to be handled by a specified rule, whether it is classified as unknown, set aside for inspection, or refused with a defined status, so that two conforming peers fail the same way<!-- story-end -->

## Notes

A peer that drops an activity silently and a peer that refuses it loudly cannot both be conforming.
The requirements that cite this story say which of those outcomes applies to which fault.
