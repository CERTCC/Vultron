# User Story `2026_099`

<!-- story-start -->As a Reporter whose tools write each report as a Common Security Advisory Framework (CSAF) 2.1 vulnerability report, I want to attach that document to the report I offer, so that the case the receiver creates starts with its title, its intended disclosure date and its exploitation status without anyone typing them in again<!-- story-end -->

## Notes

CSAF 2.1 has a profile made for private exchange during coordination, `csaf_vulnerability_report`.
The document travels as an attachment of the report, and the report keeps its own human-readable text.
See [CSAF 2.1 and Vultron](../csaf_crosswalk/overview.md).
