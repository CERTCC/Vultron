# User Story `2026_012`

<!-- story-start -->As a Peer Implementer, I want datetimes and durations to have one canonical wire serialization, so that interoperability does not rest on implementation choices<!-- story-end -->

## Notes

Embargo deadlines and ledger timestamps cross every peer boundary.
One serialization, with a time zone, means every peer reads the same instant and the same length of time.
