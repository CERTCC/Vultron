# User Story `2026_056`

<!-- story-start -->As a Participant, I want to receive a case before any ledger entry about it, so that every entry I receive can be anchored to a case I already hold<!-- story-end -->

## Notes

A copy that receives an entry before its case cannot compute the case's genesis hash, so it rejects the entry and asks for a replay from the start.
Ordering the case announcement before the entries that follow it avoids that round trip and keeps the first entries in log order.
