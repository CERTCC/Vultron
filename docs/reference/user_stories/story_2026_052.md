# User Story `2026_052`

<!-- story-start -->As a Node Operator, I want a ledger conflict that the protocol cannot reconcile to be logged at ERROR, so that a real divergence between copies reaches me and is not lost among routine recovery<!-- story-end -->

## Notes

Most sync loss repairs itself through replay and is logged as routine.
An entry that conflicts with the position a copy names, or an activity whose ledger position splits from the CASE_MANAGER's ledger, means two records of the case disagree.
That needs a person to look at it.
