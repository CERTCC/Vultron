# User Story `2026_037`

<!-- story-start -->As a Participant, I want each state change that a message carries to be recorded against the participant that the message is about, so that no participant gains or loses progress through a message about someone else<!-- story-end -->

## Notes

A status message is about its sender, a report's receipt is about its receiver, and an embargo answer is about the actor it names.
The receiving actor is often, but not always, that participant: a relayed, replayed or command-line message names a subject other than the actor that processes it.
Taking the subject from the message itself keeps every record on the right participant.
