# User Story `2026_038`

<!-- story-start -->As a Participant, I want my node to refuse to record a move of a state machine that the machine does not permit, so that my own record of the case never holds a state that the case cannot be in<!-- story-end -->

## Notes

Report management, vendor fix, deployment and public state each move only along the transitions their machines define.
A node that records a backward move or an illegal jump of its own state publishes a state that other Participants then act on.
The check belongs where the state is written, so that no call site can skip it.
