# User Story `2026_029`

<!-- story-start -->As a Peer Implementer, I want each case object, such as a report, a case, a vulnerability record, a case reference, a case participant and a participant status, to be its own type, so that my peer knows which object's rules apply to what it receives<!-- story-end -->

## Notes

A receiver acts on an object by its type.
If two of these objects shared a type, or a message carried one where the protocol expects another, a receiver would apply the rules of one object to a different object.
