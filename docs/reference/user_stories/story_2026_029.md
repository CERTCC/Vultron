# User Story `2026_029`

<!-- story-start -->As a Participant, I want the activities I send to reach the CASE_MANAGER in the order I acted, each carrying the time I state for it unchanged, so that the case record shows what I did and when I say I did it<!-- story-end -->

## Notes

The CASE_MANAGER records activities in the order they arrive, and it cannot rebuild an order it never saw.
So a Participant that wants its actions recorded in the order it took them sends them in that order.
The time a Participant states for an activity is its own claim, kept apart from the CASE_MANAGER's commit time.
A receiver that filled in a missing time from its own clock would make its guess look like the Participant's claim.
