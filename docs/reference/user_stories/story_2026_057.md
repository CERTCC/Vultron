# User Story `2026_057`

<!-- story-start -->As a Participant, I want my copy of a case to be computed only from the CASE_MANAGER's committed ledger entries, so that my copy and every other participant's reach the same case file whatever order the messages arrived in<!-- story-end -->

## Notes

Each entry carries the full activity it records, so every copy can replay the same change.
When the copy is a function of the ledger prefix alone, two copies with the same entries agree, and a copy that receives the entries late still converges.
A message outside the ledger must not leave a copy in a state that the ledger does not determine.
