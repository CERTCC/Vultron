# User Story `2026_022`

<!-- story-start -->As a Protocol Author, I want the case state machine's forbidden states, ephemeral states and forced successors to be stated as invariants, so that an implementation is checked against the model rather than against examples<!-- story-end -->

## Notes

Examples show some paths through the model.
Invariants say what no path may do, so an implementation can be checked against all of them.
