# User Story `2026_073`

<!-- story-start -->As a Participant, I want each case's ledger chain to start from a value bound to that case, its creation time and its owner, so that a chain from another case, or one made up for a case that does not exist, cannot pass as this case's history<!-- story-end -->

## Notes

The first entry of a ledger links back to a genesis hash derived from the case, not to a constant shared by every case.
The case carries the genesis hash, so a receiver can check that a ledger starts where this case's ledger must start.
A random component in the case identifier keeps the genesis hash from being predicted or spoofed.
