## Notes

A conformance claim names capability sets and Coordinated Vulnerability Disclosure (CVD) roles, for example `Case Observer + Case Decision / Vendor + Case Owner`.
The protocol requirements are machine-readable, and the state machines are defined by transition tables.
A conformance test can check an implementation against both.
See [Conformance](../vultron-spec/conformance.md).
