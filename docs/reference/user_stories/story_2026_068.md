# User Story `2026_068`

<!-- story-start -->As a Participant, I want what a case's stage allows to be judged from the case's current data at the moment I act, so that I never act on an embargo or other stage that has already ended<!-- story-end -->

## Notes

A case's stage, such as being under embargo, follows from its fields and changes whenever they change.
A stage decided at an earlier read can claim a guarantee that the current data no longer meets.
Deciding the stage from the data at each read keeps the guarantee and the data in step.
