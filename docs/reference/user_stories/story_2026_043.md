# User Story `2026_043`

<!-- story-start -->As a Participant, I want an invitee's state in a case to show only what it has agreed to, joining and consenting to the embargo when it accepts the invitation and committing to the case only when it later joins it, so that no participant appears more committed than it is<!-- story-end -->

## Notes

An invitee sees only a stub of the case before it accepts, so its acceptance cannot be a judgment of the case.
It judges the case after it has received the case and its history.
Recording the two steps apart keeps the case record from showing a commitment that the invitee has not made.
