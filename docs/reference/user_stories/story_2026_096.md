# User Story `2026_096`

<!-- story-start -->As a Participant, I want to be told when an embargo I agreed to ends or is shortened even after I have left the case or closed my part in it, so that I am never held to terms that no longer apply<!-- story-end -->

## Notes

A removed signatory stays bound by the embargo it accepted, so it still needs to learn when the embargo ends.
The CASE_MANAGER sends such a signatory a direct notice that carries nothing else, and replaying the matching ledger entry later changes nothing more.
