# User Story `2026_007`

<!-- story-start -->As a Coordinator, I want to run a simulated case before a real disclosure, with Public Awareness, Exploit Public and Attacks Observed events that arrive during the embargo, so that I can see how each Participant's process responds before the events are real<!-- story-end -->

## Notes

The protocol state machines are the same in a simulation and in a real case.
In the simulator, a Fuzzer Node stands in for a decision until a real capability answers it.
A Sentinel watches for a condition, such as an exploit going public, and when the condition is met it reports the event by calling a trigger.
See the Fuzzer Node and Sentinel entries in the [Glossary](../glossary.md).
