# User Story `2026_007`

<!-- story-start -->As a Participant in a community of interest, I want to exercise our coordination process with the other members before a real case needs it, so that we can trust the process to scale and to work when it matters<!-- story-end -->

## Notes

An exercise runs the same protocol state machines as a real case.
It can include simulated Public Awareness, Exploit Public and Attacks Observed events that arrive during an embargo.
In the simulator, a Fuzzer Node stands in for a decision until a real capability answers it.
A Sentinel watches for a condition, such as an exploit going public, and when the condition is met it reports the event by calling a trigger.
See the Fuzzer Node and Sentinel entries in the [Glossary](../glossary.md).
