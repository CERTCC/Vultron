# User Story `2026_006`

<!-- story-start -->As a Reporter, I want each request I send to get an explicit answer, and I want to see which Participant owes an answer and by when, so that I never have to guess whether my message arrived<!-- story-end -->

## Notes

A Participant answers a request with an `Accept` or a `Reject`, and the CASE_MANAGER records either answer in the case ledger.
When the CASE_MANAGER refuses an assertion, it sends a Refusal Notice that gives the reason.
An embargo invitation carries an RSVP Deadline.
See [Faults and Acknowledgments](../messages/faults_and_acknowledgements.md).
