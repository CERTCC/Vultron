# User Story `2026_006`

<!-- story-start -->As a Reporter, I want each request I send to get an explicit answer, and I want to see which Participant owes an answer and by when, so that I never have to guess whether my message arrived<!-- story-end -->

## Notes

In a case, a Participant answers an invitation or an offer with an `Accept` or a `Reject`, and the CASE_MANAGER records either answer in the case ledger.
A Participant acknowledges a report it received with a `Read`.
When a precondition guard refuses an assertion, the CASE_MANAGER sends a Refusal Notice that gives the reason.
Each embargo invitation has an RSVP Deadline, and the invitee's Embargo Consent row records it.
See [Faults and Acknowledgments](../messages/faults_and_acknowledgements.md) and the [Glossary](../glossary.md).
