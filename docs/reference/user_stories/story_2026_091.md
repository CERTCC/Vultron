# User Story `2026_091`

<!-- story-start -->As a Participant, I want each embargo invitation to carry a deadline for my answer, set by the CASE_MANAGER, no shorter than a minimum window and never after the embargo ends, so that I have time to answer and everyone knows by when I owe it<!-- story-end -->

## Notes

The invitation's deadline is its RSVP Deadline, not the embargo's end.
The CASE_MANAGER records the deadline on the invitee's consent row, and a receiver clamps a deadline that is too short instead of refusing the invitation.
