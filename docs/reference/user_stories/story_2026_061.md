# User Story `2026_061`

<!-- story-start -->As a Node Operator, I want actors that I host together to keep separate stores and to deal with each other only through protocol messages, so that a case runs the same whether its actors share a host or not<!-- story-end -->

## Notes

Running several actors in one process is a deployment choice, not a protocol feature.
An actor that reads another's store, or relies on a side channel to it, behaves differently once the actors are moved apart, and its case state then depends on where it runs.
Each actor therefore has its own execution context and its own store, chosen by its identity.
