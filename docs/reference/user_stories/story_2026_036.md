# User Story `2026_036`

<!-- story-start -->As a Participant, I want each status message I receive to update my record of its sender's state at once, so that I know where every participant and the case stand before I act<!-- story-end -->

## Notes

The protocol tells Participants about a state change by sending them a message about it.
A receiver that does not record what the message asserts acts later on a state that its sender has already left.
This story covers recording the asserted state on receipt; which participant a message is about, and which moves are allowed, are their own stories.
