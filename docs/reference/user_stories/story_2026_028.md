# User Story `2026_028`

<!-- story-start -->As an Auditor, I want the case ledger to number its entries in one gapless sequence, in the order the CASE_MANAGER recorded them, each stamped with the time it was committed, so that I can rebuild the order of case events from the ledger alone<!-- story-end -->

## Notes

The CASE_MANAGER is the only writer of the case ledger, so the order in which it records entries is the order of the case.
A gap in the sequence, two entries at one position, or a commit time that goes backward would each leave the order of events open to dispute.
The ledger records the order the CASE_MANAGER observed; it does not claim to know the order of events it never saw.
See [CASE_MANAGER and Ledger](../../topics/case_lifecycle/case_manager_and_ledger.md).
