# User Story `2026_053`

<!-- story-start -->As a Participant, I want my node to hold back new case actions until my copy of the case has caught up with the CASE_MANAGER, after a restart or while my copy has a gap, and to show that it is catching up, so that I never act on a stale view of the case<!-- story-end -->

## Notes

After a restart, or with a gap in its ledger, a node cannot know what it missed.
An action taken then can contradict an entry that the node has not yet seen.
Showing the catching-up condition tells the person or tool driving the node why an action waits.
