# User Story `2026_031`

<!-- story-start -->As a Participant, I want my own progress on a case kept apart from the state that the whole case shares, so that my progress never changes the embargo or public state that binds everyone, and a case-wide event never erases my progress<!-- story-end -->

## Notes

Each Participant has its own report management (RM) state and its own vendor fix and deployment (VFD) state.
The embargo (EM) state and the public, exploit and attack (PXA) state belong to the case and are the same for every Participant.
A move on one side must not write the other side, or one Participant's step changes what binds the others, and a shared event overwrites one Participant's progress.
