# User Story `2026_097`

<!-- story-start -->As a Participant, I want an invitation to join a case to carry the embargo in force, and to be replaced by one that names it when that embargo changes before I answer, so that I agree to join under the terms that actually apply<!-- story-end -->

## Notes

An invitation to join carries the embargo in force and no open revision; the invitee learns of an open revision after it joins.
Accepting a replaced invitation is refused with the replacement named, and rejecting one is honored.
