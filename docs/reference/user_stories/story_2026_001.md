# User Story `2026_001`

<!-- story-start -->As a Case Owner, I want each Participant's Embargo Consent recorded separately for each version of the embargo, so that I know who agreed to the terms in force and no Participant is bound by terms it did not see<!-- story-end -->

## Notes

The case keeps every proposed embargo in its Embargo Register, and a revision is a new register entry.
Each Participant has one consent row for each entry.
A Participant is a signatory only when its row for the Active Embargo is `AGREED`.
An answer to a replaced embargo cannot change the row for the embargo in force.
See [Embargo Lifecycle](../../topics/behavior_logic/use-cases/embargo-lifecycle.md).
