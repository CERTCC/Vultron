# User Story `2026_069`

<!-- story-start -->As a Participant, I want every event in a case recorded in the case ledger, including a rejection, an ask, an expired invitation, a processing fault attributed to the case and the CASE_MANAGER's own acts, so that the record leaves out nothing that bears on the case<!-- story-end -->

## Notes

A case event is any activity the CASE_MANAGER admits at the case layer, whoever sent it.
A rejection or an expiry is as much a part of the case's history as an acceptance, so it is recorded the same way.
Only a short, named list of activities is exempt, such as those that come before the case exists or that only manage the ledger itself, and a coverage test checks that every other act reaches a commit, or names the open issue that tracks a missing one.
