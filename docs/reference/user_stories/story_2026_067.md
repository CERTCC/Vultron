# User Story `2026_067`

<!-- story-start -->As a Reporter, I want each offer of my report to name one recipient and to carry its own id, so that I can tell apart the cases that different recipients open from the same report<!-- story-end -->

## Notes

A Reporter that gets no answer from its first recipient often offers the same report to a Coordinator, and either recipient may then open a case.
With one recipient and one id per offer, each attempt, and the case that follows from it, is identified by the pair of report and recipient.
