# User Story `2026_010`

<!-- story-start -->As a Peer Implementer, I want every response activity (Accept, Reject, TentativeReject) to have one specified wire encoding, so that my peer interoperates with others without guessing<!-- story-end -->

## Notes

A response that two implementations encode differently is one that neither can read from the other.
The requirements that cite this story fix the activity type and the object each response carries.
