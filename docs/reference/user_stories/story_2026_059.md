# User Story `2026_059`

<!-- story-start -->As a Participant, I want every change to a case to go through its CASE_MANAGER and to enter the case only by the one message that records it, so that the case has one order of events and one record that every copy follows<!-- story-end -->

## Notes

The CASE_MANAGER is the authority for the case state: Participants address case messages to it, and it alone commits and replicates them.
Each kind of case record enters the case by one attaching message, so a copy never has to choose between two ways a record could have arrived.
The CASE_MANAGER's observation order is the case's order of events.
