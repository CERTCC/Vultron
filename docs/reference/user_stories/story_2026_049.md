# User Story `2026_049`

<!-- story-start -->As a Participant, I want every copy of a case and every message about it to name the ledger position it reflects, so that any two parties can tell which of them is behind<!-- story-end -->

## Notes

A case copy is a projection of the ledger up to some entry, and that entry is its ledger position.
When the position travels with the case and with each case message, a receiver compares positions in place of guessing from timestamps or content.
A copy that names no position cannot be placed and is refused.
