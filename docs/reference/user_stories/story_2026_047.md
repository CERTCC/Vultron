# User Story `2026_047`

<!-- story-start -->As a Participant, I want the CASE_MANAGER to answer a report that my copy has fallen behind by sending me what I lack, the missing entries in order or a fresh copy of the case, so that my copy catches up without anyone stepping in<!-- story-end -->

## Notes

Messages get lost and nodes restart, so a copy can fall behind or diverge in normal operation.
The CASE_MANAGER knows how far each peer has acknowledged and can replay the entries after that point, or send its current case when the copy has diverged.
A Participant may also ask on its own to catch up.
