# User Story `2026_094`

<!-- story-start -->As a Participant, I want every party to answer an embargo proposal promptly, and to be free to proceed as if no embargo were agreed when an answer does not come in time, so that a stalled negotiation never holds the case<!-- story-end -->

## Notes

The protocol suggests answering within the period in the Participant's vulnerability disclosure policy or within 14 days, whichever is shorter.
A party may treat a silence as a refusal when it decides how to proceed, but the CASE_MANAGER records an unanswered invitation as timed out, never as a refusal ([2026_092](story_2026_092.md)).
