# User Story `2026_004`

<!-- story-start -->As a Participant with limited response capacity, I want to let software make routine case decisions for me, such as accepting an invitation or answering an embargo proposal, so that I can use that capacity where it matters most<!-- story-end -->

## Notes

The protocol state machines are explicit, and they refuse invalid transitions.
Each decision a Participant must make is a Call-Out Point.
A capability answers a Call-Out Point, and a capability implementation can be a function, a rules engine, a human workflow or a large language model (LLM) agent.
See [Annex G: Capability Shapes](../vultron-spec/annex-g-capability-shapes.md).
