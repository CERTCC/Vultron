# User Story `2026_030`

<!-- story-start -->As a Participant, I want my copy of a case to change only on messages from a CASE_MANAGER I already had reason to trust, so that an actor posing as the CASE_MANAGER cannot plant a case in my records or change one<!-- story-end -->

## Notes

A message can name any actor as the CASE_MANAGER, and an authenticated transport shows only who sent the message.
A Participant trusts a CASE_MANAGER for a case only through the bootstrap trust handoff: a relationship it had before the case arrived, such as the report it sent or the invitation it accepted.
Until that trust exists, a message about the case changes nothing in the Participant's records.
See [Case Ledger Synchronization](../../topics/case_lifecycle/case_ledger_sync.md).
