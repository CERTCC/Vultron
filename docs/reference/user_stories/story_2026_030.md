# User Story `2026_030`

<!-- story-start -->As a Participant, I want an embargo to hold only while secrecy still protects users, so that no one is asked to keep a secret that the public or attackers already have<!-- story-end -->

## Notes

Public awareness, a public exploit and observed attacks each end the protection that an embargo gives.
After any of them, an embargo that stays in force holds back information that defenders need, and a new embargo cannot protect anything.
The case state model therefore ends the embargo on these events and refuses a new one.
