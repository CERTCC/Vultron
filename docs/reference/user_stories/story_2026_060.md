# User Story `2026_060`

<!-- story-start -->As a Participant, I want everything that follows from an event to happen when the event is processed, without anyone having to ask, so that the case never waits on a step that nobody knows to take<!-- story-end -->

## Notes

When the CASE_MANAGER accepts a Participant's message, it commits the ledger entry and broadcasts it to the case as part of processing that message.
A consequence that waited for a separate request or a person to act would leave the case stalled at a point that no message reveals.
Explicit external decision points are the exception, and they are declared.
