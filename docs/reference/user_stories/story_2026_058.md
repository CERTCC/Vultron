# User Story `2026_058`

<!-- story-start -->As a Participant, I want each change to my copy of a case to happen whole or not at all, so that a failure part-way through never leaves my copy recording a change whose effects are missing<!-- story-end -->

## Notes

A ledger entry can have several effects, such as ending an embargo, updating a participant's status or attaching a note.
If the entry is stored while one effect failed, the copy claims a state it does not hold, and the entry is never applied again.
A sequence that cannot reach its routing prerequisites, such as the CASE_MANAGER's identity, likewise changes nothing.
