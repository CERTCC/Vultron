# User Story `2026_050`

<!-- story-start -->As a Participant, I want a full case copy from the CASE_MANAGER to replace my case file only when the copy is ahead of mine and agrees with the entries I hold, so that a late or conflicting copy never rolls my case back or forks it<!-- story-end -->

## Notes

A full copy can arrive late, after entries that make it stale, or can disagree with an entry that the Participant already holds.
Comparing ledger positions decides whether the copy is ahead, behind or in conflict.
Entries that the copy already covers then become no-ops, and an entry that conflicts with the copy is refused.
