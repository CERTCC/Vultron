# User Story `2026_076`

<!-- story-start -->As a Participant, I want the case ledger to record a message only after the message has been sent or received, so that the record never claims an exchange that did not happen<!-- story-end -->

## Notes

If the commit fails after the outbox write, a retry rebuilds the message under its first id, and the outbox does not send it twice.
Committing first would leave a record of a message that may never have left the node.
