# User Story `2026_041`

<!-- story-start -->As a Participant, I want the case's shared embargo and public state to change only when the case adopts a change that a participant reports, and each adopted change to be recorded once in the case ledger without losing a public fact already known, so that every participant sees the same shared state and the ledger shows when it changed<!-- story-end -->

## Notes

The embargo state and the public, exploit and attack state are shared by every Participant in a case.
A Participant's report of such a change is a claim until the case adopts it; adoption then writes one new case status to the ledger.
A repeat of the same state is not a change, and an adopted state never clears a public fact that the case already holds.
