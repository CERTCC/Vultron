# User Story `2026_045`

<!-- story-start -->As a Participant, I want my copy of a case to refuse any ledger entry that does not follow from the entries it holds, and to tell the CASE_MANAGER how far it got, so that a lost, reordered or conflicting entry is found at once and never silently absorbed<!-- story-end -->

## Notes

Each ledger entry names the hash of the entry before it, so a copy can tell whether a new entry extends what it holds.
An entry that does not extend the chain means that something was lost, reordered or forked.
Telling the CASE_MANAGER the last entry accepted is what lets it send the right entries next.
