# User Story `2026_002`

<!-- story-start -->As a Participant, I want every change to the case recorded in one hash-chained case ledger that every Participant holds a copy of, so that a dispute about who knew what, and when, is settled by the record<!-- story-end -->

## Notes

The CASE_MANAGER is the only writer of the case ledger.
Each Case Ledger Entry is chained to the entry before it, and each Participant Case Replica copies the entries.
The ledger timestamps also make it possible to measure a case against the Ordering Preferences and compute the time between events.
See [Case Manager and Ledger](../../topics/case_lifecycle/case_manager_and_ledger.md) and [Measuring Coordinated Vulnerability Disclosure (CVD)](../../topics/measuring_cvd/index.md).
