# User Story `2026_054`

<!-- story-start -->As a Participant, I want a case's full details to reach only the participants that have joined it, so that an invitee decides from the invitation alone and nobody obtains the case by asking to resynchronize<!-- story-end -->

## Notes

An invitee receives a stub of the case and decides from it whether to join; the case arrives only after it accepts.
Recovery paths that send a full case copy apply the same rule, so a resynchronization request from a party that is not an active participant gets nothing.
