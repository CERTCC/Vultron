# User Story `2026_079`

<!-- story-start -->As a Participant, I want the CASE_MANAGER to resend an invitation that I still owe an answer to whenever my node reports its position in the case ledger, unchanged and at a bounded rate, so that an invitation lost in delivery still reaches me without flooding my node<!-- story-end -->

## Notes

An invitation is owed an answer only while that answer can still count, and only the last one sent for an embargo is owed.
A resend is the activity as first sent, with the same id, position and deadline, so a resend is never taken for a new invitation.
A resend is not a case event: it is not recorded in the ledger and does not change the outcome of the activity that prompted it.
