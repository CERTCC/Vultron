# User Story `2026_046`

<!-- story-start -->As a Participant, I want my node to check each ledger entry's hash against its content before it keeps the entry, and to tell the CASE_MANAGER when the check fails, so that a damaged entry never enters my copy of the case<!-- story-end -->

## Notes

An entry whose content does not reproduce its stated hash was damaged or altered on its way.
Keeping it would put a change that the CASE_MANAGER never made into the copy, and every later entry would chain from it.
A fault report lets the CASE_MANAGER see that a delivery went wrong.
