# User Story `2026_003`

<!-- story-start -->As a Case Owner, I want to transfer case ownership to another Participant inside the case, so that the case keeps its Participants, its embargo and its ledger history, and no Participant has to report the vulnerability again<!-- story-end -->

## Notes

A Case Ownership Transfer moves the `CASE_OWNER` role from one Actor to another.
The CASE_MANAGER routes every step, so every Participant receives the ledger entries that record the transfer.
A Vendor can hand a case to a Coordinator this way, and one Coordinator can hand a case to another.
See [Ownership Transfer](../../topics/case_lifecycle/ownership_transfer.md).
