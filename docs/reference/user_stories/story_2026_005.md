# User Story `2026_005`

<!-- story-start -->As a Participant that runs its own Actor, I want my Participant Case Replica to reach the same state as the CASE_MANAGER's ledger, whatever order the messages arrive in, so that I can take part in a case without a shared platform<!-- story-end -->

## Notes

Each organization runs its own Actor, and Actors exchange ActivityStreams 2.0 (AS2) activities over ActivityPub.
The CASE_MANAGER coordinates the case, but each Participant keeps its own Participant Case Replica.
A Participant Case Replica that missed entries catches up from the ledger.
See [Case Ledger Synchronization](../../topics/case_lifecycle/case_ledger_sync.md) and [Annex E: ActivityPub](../vultron-spec/annex-e-activitypub.md).
