# User Story `2026_080`

<!-- story-start -->As a Participant, I want a case whose vulnerability is still secret to be under an embargo from the moment the case is created, on the Case Owner's default terms or else on a protocol default of three to five days, so that the vulnerability is protected before anyone has negotiated<!-- story-end -->

## Notes

A case starts under an embargo in force, not under a proposal, so no window opens between the report and the first agreement.
The Case Owner's own default applies when it has one, and the protocol default applies otherwise.
A case whose vulnerability is already public, exploited or attacked at creation starts with no embargo.
