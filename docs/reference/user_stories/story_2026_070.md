# User Story `2026_070`

<!-- story-start -->As a Participant, I want each change to a case recorded as its own ledger entry, one entry for each change and no change without one, so that the record counts every change once and the case file never holds a change that the record lacks<!-- story-end -->

## Notes

An act and the changes it causes are different facts, so each gets its own entry, in the order the CASE_MANAGER writes them.
Committing two entries for one change, or making a change with no entry, would leave the case file and the record disagreeing about what happened.
