# User Story `2026_063`

<!-- story-start -->As a Node Operator, I want every change to a case's state committed to my node's store before it counts as done, so that a restart loses no case state and no replication progress<!-- story-end -->

## Notes

State held only in memory disappears when the node restarts, and a change that was reported but not stored is then a change the node denies.
Per-peer replication progress is stored too, so the CASE_MANAGER does not replay a whole ledger to every peer after a restart.
Stored objects read back as the same objects.
