# User Story `2026_075`

<!-- story-start -->As a Participant, I want the CASE_MANAGER to send each change it records in a case to every active participant, so that every participant holds the same record of the case and none of them depends on another to pass a change on<!-- story-end -->

## Notes

Each recorded change is sent as the committed ledger entry, wrapped in a transport envelope, to every active participant.
The CASE_MANAGER's own notices about the case, such as the notice that an embargo has ended, go to the same recipients.
The CASE_MANAGER never addresses a copy to itself, and it skips a send that would have no recipient instead of sending one to nobody.
