# User Story `2026_085`

<!-- story-start -->As a Participant, I want each embargo proposal to be recorded by the CASE_MANAGER and sent to every other participant as an invitation that names who proposed it, so that every participant answers the same terms and none depends on the proposer to reach it<!-- story-end -->

## Notes

The CASE_MANAGER commits the proposal and then relays an invitation to each participant, naming the proposer in `attributedTo`.
A participant that joins while a proposal is open is invited to it after it holds the case.
Each invitation has one invitee, and a proposal that repeats the end time of terms already on the table changes nothing.
