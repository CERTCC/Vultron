# User Story `2026_032`

<!-- story-start -->As a Node Operator, I want my node to explain a processing failure only to an authenticated sender, and without its internal diagnostics, so that the explanation helps a peer fix its message without helping an attacker probe my node<!-- story-end -->

## Notes

A failure report tells a peer what went wrong with its message.
Sent to an unauthenticated sender, or with stack traces and parser details, the same report tells an attacker how the node reads its input.
The diagnosis stays in the node's own log.
