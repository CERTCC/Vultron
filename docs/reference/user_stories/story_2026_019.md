# User Story `2026_019`

<!-- story-start -->As a Node Operator, I want pending assertions and retries to time out on documented defaults, so that stale state does not accumulate on my node<!-- story-end -->

## Notes

A pending assertion that no answer ever arrives for, and a retry that never stops, both grow without bound.
A documented default tells the operator when each one ends.
