| State | Meaning |
|---|---|
| No Embargo | No embargo is in scope for this participant. Also the state reached when an embargo ends |
| Invited | The participant has an embargo invitation outstanding; its response is pending |
| Signatory | The participant has accepted the current embargo terms |
| Lapsed | The participant was a signatory, the case embargo entered Revised, and it has not yet accepted the new terms |
| Declined | The participant refused the terms, or did not answer before the deadline |
