# Annex D Possible Case Histories

{% include-markdown "./_full-page-tip.md" %}

This page holds informative Annex D of the [Vultron Protocol Specification](index.md): how the ordering constraints of Coordinated Vulnerability Disclosure (CVD) reduce the Case State (CS) event orderings to 70 possible case histories.
Each history is an input string to a Deterministic Finite Automaton (DFA), and its notation sits beside that of the Report Management (RM) and Embargo Management (EM) models.
