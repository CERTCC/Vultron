# Protocol Specification Revision Log

This page records each draft of the [Vultron Protocol Specification](index.md), with its version identifier, its date, and what changed in it.
The newest draft is first.

## Version identifiers

Each draft of the specification has a version identifier of the form `draft-N`.
`N` is the number of the draft.
The first draft is `draft-1`, and each later draft adds one.

A draft is fixed when it is tagged in the Vultron repository.
Until the tag, the text of the draft can still change.
After the tag, a change to the text goes into the next draft, with a new entry on this page.
Thus a tagged version identifier always names one text, and a reader can cite the text they read.

The version identifier names the text of the specification only.
It is separate from the [release version](../versioning.md) of the Vultron repository, which names a snapshot of the whole repository.

The date of a draft is the date on which its entry was added to this page, in the `YYYY-MM-DD` format.
The tag of a draft records the date on which the draft was fixed.

## Draft 1

- **Date:** 2026-11-06
- **Status:** Draft

Draft 1 is the first draft of the specification.
It is not tagged yet, so its text can still change.
It has no earlier draft, so this entry lists what the draft holds, not what changed.

- The body sections, from §1 Introduction to §17 References, as listed in the [parts of the specification](index.md#parts).
- The §14 Requirements Catalog, which renders the `protocol` and `foundation` requirement tiers.
- Annexes A to G, which illustrate and explain the protocol and are not normative.
- The [Open Questions](open-questions.md) that this draft leaves unresolved.
