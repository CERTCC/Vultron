## Annex A — Worked Example: Single-Vendor CVD [I]

This annex traces one two-party case from first contact to closure.
Each step names the message sent and the state transition it reports, so the sequence can be read against the state machine sections ([§6 Report Management (RM) State Machine](tracking-models.md#6-report-management-rm-state-machine-n) through [§9 Participant Embargo Consent (PEC) State Machine](tracking-models.md#9-participant-embargo-consent-pec-state-machine-n)).

Four embargo outcomes are shown — accepted, rejected, countered, and accepted then revised — because embargo negotiation is where two-party cases most often diverge.
