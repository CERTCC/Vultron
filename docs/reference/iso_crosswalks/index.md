# Standards Crosswalks

{% include-markdown "../../includes/not_normative.md" %}

Three ISO/IEC standards and one prioritization framework overlap with the Vultron Protocol.
Each crosswalk below maps that document's clauses to two places: the explanation page that covers the same ground, and the section of the [Vultron Protocol Specification](../vultron-spec/index.md) that states the normative requirement.
A program that already follows one of these standards can use its crosswalk to find which protocol behavior each clause it satisfies corresponds to.

| Document | Title | Crosswalk |
| --- | --- | --- |
| [ISO/IEC 30111:2019](https://www.iso.org/standard/69725.html){:target="_blank"} | **Information technology — Security techniques — Vulnerability handling processes** | [ISO/IEC 30111](iso_30111_2019.md) |
| [ISO/IEC 29147:2018](https://www.iso.org/standard/72311.html){:target="_blank"} | **Information technology — Security techniques — Vulnerability disclosure** | [ISO/IEC 29147](iso_29147_2018.md) |
| [ISO/IEC TR 5895:2022](https://www.iso.org/standard/81807.html){:target="_blank"} | **Cybersecurity — Multi-party coordinated vulnerability disclosure and handling** | [ISO/IEC TR 5895](iso_5895_2022.md) |
| [SSVC](https://certcc.github.io/SSVC/){:target="_blank"} | **Stakeholder-Specific Vulnerability Categorization** | [SSVC](../ssvc_crosswalk.md) |

The specification's own account of how it relates to these standards is [§1.3 Relationship to Existing Standards](../vultron-spec/index.md#13-relationship-to-existing-standards).
