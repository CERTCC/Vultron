# Open Questions

Vultron is a work in progress, and the project keeps its unresolved questions where a reader can find them.
They are kept in two lists, because they are questions of two different kinds.

- [Protocol Specification: Open Questions](../reference/vultron-spec/open-questions.md) lists what the [Vultron Protocol Specification](../reference/vultron-spec/index.md) leaves unresolved at the time of issue.
  An implementer reads it to know which behavior the specification does not yet fix.
- [Open Design Questions](../topics/future_work/open_questions.md) lists the design questions about work the project has not done yet, such as moving the message vocabulary between organizations.
  Each question also appears at the point in the text where it first applies.

To raise a question that is on neither list, see [Proposing a Change](proposing_a_change.md).
