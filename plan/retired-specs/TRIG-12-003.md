# TRIG-12-003 (retired)

- **Retired**: 2026-11-05 (#4190)
- **Why**: The golden OpenAPI snapshot the rule names is deleted. It was a gating scaffold for the ADR-0110 trigger-stack collapse, that migration landed on 2026-10-01, and the frozen file also pinned FastAPI's own error schemas, so every FastAPI or Pydantic bump turned red until an agent regenerated it (#4190). The trigger contract is now held by the route-to-registry bijection (TRIG-12-007) and the exact-response-key test (TRIG-12-002).
- **Last text**:

```yaml
  - id: TRIG-12-003
    priority: MUST_NOT
    kind: project
    statement: >-
      The trigger API contract MUST NOT change without a deliberate update to a
      committed golden OpenAPI snapshot. The contract is the paths, `operation_id`s,
      status codes, summaries, descriptions and request schemas.
    rationale: >-
      Some changes touch all trigger routes at one time, for example a new
      `response_model` on each route. Such a change needs mechanical evidence that the
      contract that clients see did not change. Only a snapshot taken before the routes
      change gives this evidence. A snapshot taken after the change records the change
      as the baseline.
    verification: >-
      `test/adapters/driving/fastapi/test_openapi_trigger_snapshot.py::test_trigger_openapi_contract_matches_committed_snapshot`
      compares `app.openapi()` for the trigger and demo paths against the committed
      snapshot and fails on any difference.
    adr:
    - ADR-0110
```
