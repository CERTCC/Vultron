# VAM-04-019 (retired)

- **Retired**: 2026-10-27 (#5109)
- **Replacement**: SYNC-18-002
- **Why**: ADR-0156 moves the full-case Invite's and its replies' position off `content` onto `ledgerPosition`; SYNC-18-002 and SYNC-18-003 state who produces and who parses it.
- **Last text**:

```yaml
  - id: VAM-04-019
    priority: MUST
    kind: project
    statement: >-
      In this implementation, the `content` of the full-case Invite and of its replies
      (VAM-04-011 to VAM-04-014) MUST be the JSON dump, under the model's wire aliases,
      of the core `LedgerPosition` model, and MUST be produced only by
      `vultron.wire.as2.factories`. A receiver MUST parse it with
      `LedgerPosition.model_validate_json` at the parse edge (ADR-0032).
    rationale: >-
      One model and one producer keep the sender's string and the receiver's parse from
      drifting apart. Parsing at the edge hands the core a typed position, so no core
      code re-checks a string it could not have received (ADR-0032).
    verification: >-
      `test/wire/as2/factories/test_full_case_invite_factories.py::test_invite_targets_the_plain_case_uri_and_carries_the_floor_in_content`
      confirms the factory writes the position's alias dump into `content`;
      `test/core/use_cases/received/actor/test_full_case_invite.py::test_a_reply_with_unparseable_content_is_refused_at_the_edge`
      confirms a reply whose `content` does not parse as a `LedgerPosition` is refused
      at the parse edge; inspection of `vultron/wire/as2/factories/case.py` confirms the
      factories build `content` from `LedgerPosition`.
    relationships:
    - rel_type: implements
      spec_id: VAM-04-011
    adr:
    - ADR-0032
```
