# ENC-01-003 (retired)

- **Retired**: 2026-10-28 (#5379)
- **Replacement**: SIG-02-001
- **Why**: Signing reads every author's key from the author's own actor profile (ADR-0164), so the CASE_MANAGER no longer hands its key to each participant on add.
- **Last text**:

```yaml
  - id: ENC-01-003
    priority: MUST
    kind: protocol
    statement: >-
      The actor enacting the `CASE_MANAGER` role MUST share its public key with each case
      participant when they are added to the case
    rationale: >-
      A new participant needs the CASE_MANAGER's key to encrypt messages to it
      (ENC-02-001) and to verify its signatures from the first message of the case.
      Delivering the key with the add gives the participant the key from the actor it
      already deals with for the case, without a separate fetch.
    verification: Integration tests confirm that when a participant is added to a case, the outbound activity includes
      the CASE_MANAGER's public key.
    scope:
    - production
    stories:
    - story_2022_090
```
