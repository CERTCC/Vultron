# CS-06-001 (retired)

- **Retired**: 2026-11-02 (#5390)
- **Replacement**: CS-18-001
- **Why**: CS-18-001 states the module-size rule. CS-06-001 stated the same rule with a different line count, so two thresholds governed one decision.
- **Last text**:

```yaml
  - id: CS-06-001
    priority: SHOULD
    kind: project
    statement: Prefer modules that are < ~400 lines; split large modules by responsibility and avoid single-file catchalls
    rationale: >-
      A small module with one responsibility is easier to read, review and test. A
      catch-all file collects unrelated code, so changes to it conflict more often,
      and a reader must scan code that has nothing to do with the task.
```
