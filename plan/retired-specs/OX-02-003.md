# OX-02-003 (retired)

- **Retired**: 2026-11-03 (#5339)
- **Why**: Each DataLayer is scoped to one actor (ADR-0073), so the explicit-actor record_outbox_item form is gone and outbox_append always queues in the emitting actor's own outbox (DL-04-004).
- **Last text**:

```yaml
  - id: OX-02-003
    priority: MUST
    kind: project
    verification_debt: '#2575'
    statement: >-
      When an adapter enqueues an activity on behalf of a specific emitting actor, it MUST
      enqueue against that actor's outbox explicitly (e.g. record_outbox_item(actor_id, ...)),
      NOT via a scope-dependent append that targets the DataLayer instance's own actor scope.
      A scope-dependent append is correct only when the DataLayer is guaranteed to be scoped
      to the emitting actor.
    rationale: >-
      An activity that is queued in the wrong actor's outbox goes out from the wrong
      actor, or it does not go out. For example, the CASE_MANAGER then does not receive
      a participant's Reject(CaseLedgerEntry), and the participant's replica stays out
      of step. See ADR-0037.
    adr:
    - ADR-0037
```
