# CBT-03-004 (retired)

- **Retired**: 2026-10-29 (#5334)
- **Replacement**: SYNC-17-008
- **Why**: The receiver's bootstrap replay Question had no handler and asked for Create(VulnerabilityCase), which no longer delivers a case copy (PCR-02-005); ADR-0163 gives recovery of a dropped Invite to the CASE_MANAGER, prompted by the participant's post-seed position statement (SYNC-17-008).
- **Last text**:

```yaml
  - id: CBT-03-004
    priority: SHOULD
    kind: project
    statement: When bootstrap has not arrived in time, the receiver SHOULD request a replay from the original report receiver
      / case creator by sending an `as_Question` activity (`vultron.wire.as2.vocab.base.objects.activities.intransitive.as_Question`)
      asking for the bootstrap `Create(VulnerabilityCase)` to be resent. The `target` of the `as_Question` SHOULD be set to
      the `case_actor_id` recorded on the `VultronPendingCaseInbox` entry.
    rationale: >-
      A receiver whose queue expired has lost messages it could not yet trust, and
      only a case copy lets it trust the next ones. The `Question` asks the actor
      that the queue record names for that case copy, so the receiver does not
      depend only on other traffic to get it.
```
