# CM-13-001 (retired)

- **Retired**: 2026-10-08 (#4292)
- **Replacement**: MSM-07-003
- **Why**: ADR-0122 rev 2 retires the two-audience rule: the case owner's decision for the case is Accept(EmbargoEvent, target=Case) (MSM-07-008), and Accept(Invite(EmbargoEvent)) is always the sender's own consent (MSM-07-003), so no handler branches on whether the sender is the owner.
- **Last text**:

```yaml
  - id: CM-13-001
    priority: MUST
    kind: protocol
    statement: When processing an `Accept(Invite(EmbargoEvent))` or embargo-accept trigger, the handler MUST determine whether
      the accepting actor is the case owner (`VulnerabilityCase.attributed_to == actor_id`) and apply the correct state transitions
      accordingly
    rationale: The case owner's acceptance is the authoritative signal for advancing the shared EM state. Non-owner participants
      update only their own consent state.
    verification: Integration tests in `test/demo/` confirm that the embargo-accept handler
      checks `VulnerabilityCase.attributed_to == actor_id` before applying state transitions.
    stories:
    - story_2022_048
    - story_2022_023
```
