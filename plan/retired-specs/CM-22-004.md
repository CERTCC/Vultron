```yaml
  - id: CM-22-004
    priority: MUST
    kind: protocol
    statement: >-
      The CASE_MANAGER MUST initialize the default embargo for the new case before
      emitting `Create(VulnerabilityCase)` to the report receiver (the CASE_OWNER).
    rationale: >-
      Embargo state is protocol-significant.  Deferring initialization to the
      report receiver or to a later message would produce a window in which
      embargo-gated operations are undefined (ADR-0041, CP-09-003).  The
      CASE_MANAGER is the only actor that can initialize it authoritatively at
      case creation; the actor default it applies is the CASE_OWNER's policy,
      carried on the proposal (CP-01-009, CP-01-010).
    verification: Integration tests in `test/demo/` confirm that the CASE_MANAGER initializes the
      default embargo before emitting `Create(VulnerabilityCase)` to the report receiver.
```
