# CLP-02-019 (retired)

- **Retired**: 2026-11-03 (#5573)
- **Why**: Before 1.0 Vultron supports one protocol and storage version (ADR-0175): eventType is an unknown key, set aside on receipt (MV-11-003) and refused in a stored row by extra=forbid (MV-11-004), with no message naming the rename.
- **Last text**:

```yaml
  - id: CLP-02-019
    priority: MUST
    kind: project
    statement: >-
      This codebase MUST refuse a stored or received entry that still carries the
      retired key `eventType`, never reading it through an alias. The refusal message
      names the rename.
    rationale: >-
      Stored data has no backwards-compatibility requirement. An alias would keep two
      names for one field in use, so the old key is refused and not translated.
    verification: >-
      Tests marked `CLP-02-019` in
      `test/core/models/test_case_ledger_entry_semantic_type.py` confirm that a payload
      carrying `eventType` beside `semanticType` is refused with an error naming the
      rename, and that a stored row carrying the retired field is refused. Tests marked
      `CLP-02-019` in `test/wire/as2/test_unknown_key_disposition.py` confirm that a
      received inline entry, or any other inline object, carrying `eventType` is refused
      at parse with a message naming the rename.
    relationships:
    - rel_type: extends
      spec_id: CLP-02-015
    adr:
    - ADR-0140
```
