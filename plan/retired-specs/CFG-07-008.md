# CFG-07-008 (retired)

- **Retired**: 2026-11-02 (#5390)
- **Why**: It describes a seed-YAML sub-block loader, `_actor_config_from_seed_yaml()`, that no longer exists. `load_actor_config()` in `vultron/config/app.py` returns `get_config().actor`, and `AppConfig` loads the whole file through `YamlConfigSource`, so no sub-block loader remains to constrain.
- **Last text**:

```yaml
  - id: CFG-07-008
    priority: MUST
    kind: project
    verification_debt: '#2575'
    statement: A YAML sub-block loader (e.g., `_actor_config_from_seed_yaml()`) MUST check for the presence of the target
      key in the raw YAML dict before calling `model_validate`. If the key is absent, the loader MUST return `None` so the
      caller falls through to the next source in the resolution order (env vars, then defaults).
    rationale: >-
      `model_validate({})` succeeds on a model whose fields all have defaults, and it
      returns an instance that holds only defaults. A loader that validates a missing
      key therefore cannot tell an absent key from a key set to its defaults. It returns
      that instance and skips the sources after the file, such as environment variables.
      A check for the key before validation keeps the order of sources.
```
