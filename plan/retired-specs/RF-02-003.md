# RF-02-003 (retired)

- **Retired**: 2026-10-28 (#5255)
- **Replacement**: RF-02-004
- **Why**: Duplicated RF-02-004, which states the same protocol rule (the Accept's object is the Offer itself) with the inline-or-by-reference wording.
- **Last text**:

```yaml
  - id: RF-02-003
    priority: MUST
    kind: protocol
    statement: >-
      Accepting an Offer of an object MUST reference the Offer activity in the `object` field
      of the Accept response
    rationale: >-
      The Offer is the proposal the initiator tracks. Referencing it ties the Accept to
      that one proposal, even when the same object has been offered more than once.
    verification: Unit tests in `test/wire/as2/vocab/test_actvitities/test_inline_object_required.py` confirm that
      `Accept` responses built from an `Offer` carry the full `Offer` activity object in the `object` field.
    stories:
    - story_2022_048
    - story_2022_054
```
