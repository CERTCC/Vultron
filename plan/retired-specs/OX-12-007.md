# OX-12-007 (retired)

- **Retired**: 2026-11-03 (#5339)
- **Why**: Named the ASGIEmitter, which ADR-0042 removed. OX-12-002 makes the HTTP adapter the default emitter, and OX-12-006 and OX-12-003 keep an in-process shortcut out.
- **Last text**:

```yaml
  - id: OX-12-007
    priority: MUST_NOT
    kind: project
    verification_debt: '#2575'
    statement: >-
      The ASGIEmitter in-process delivery adapter MUST NOT be wired as the default
      emitter.
    rationale: >-
      Wiring ASGIEmitter as default restores the in-process shortcut prohibited by
      OX-12-001 and masks inter-actor delivery bugs. See ADR-0042.
    relationships:

      spec_id: OX-12-002
```
