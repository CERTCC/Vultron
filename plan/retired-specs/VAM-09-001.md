# VAM-09-001 (retired)

- **Retired**: 2026-11-03 (#5469)
- **Replacement**: VAM-01-007
- **Why**: It restates VAM-01-007, which already requires MessageSemantics.UNKNOWN when no registered pattern matches, with the same VAM-01-009 exception.
- **Last text**:

```yaml
  - id: VAM-09-001
    priority: MUST
    kind: project
    statement: >-
      An inbound AS2 activity that does not match any registered pattern MUST be
      assigned `MessageSemantics.UNKNOWN`, except where VAM-01-009 requires
      `MessageSemantics.UNKNOWN_UNRESOLVABLE_OBJECT`
    rationale: >-
      A received activity needs one defined result even when no pattern describes it, so
      that the inbox can refuse and log it in place of failing on an exception.
    verification: A unit test confirms that when the `SEMANTIC_REGISTRY` loop exhausts all entries without a
      match, `find_matching_semantics()` returns `MessageSemantics.UNKNOWN` as the fallback value.
```
