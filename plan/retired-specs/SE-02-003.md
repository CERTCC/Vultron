# SE-02-003 (retired)

- **Retired**: 2026-11-05 (#5858)
- **Replacement**: VAM-01-007
- **Why**: It restates VAM-01-007, which already requires MessageSemantics.UNKNOWN when no registered pattern matches, with the same VAM-01-009 exception.
- **Last text**:

```yaml
  - id: SE-02-003
    priority: MUST
    kind: project
    statement: >-
      `find_matching_semantics()` MUST return `MessageSemantics.UNKNOWN` if no pattern
      matches, except where VAM-01-009 requires `UNKNOWN_UNRESOLVABLE_OBJECT`.
    rationale: >-
      The dispatcher needs a semantic type for each received activity. With a defined
      fallback, the receiver logs and handles an unrecognized activity in one place. The
      matcher does not fail.
    verification: >-
      A unit test confirms that `find_matching_semantics()` returns
      `MessageSemantics.UNKNOWN` when no registered `ActivityPattern` in
      `SEMANTIC_REGISTRY` matches the supplied activity.
```
