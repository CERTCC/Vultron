# VSD-01-001 (retired)

- **Retired**: 2026-11-12 (#6336)
- **Replacement**: SHD-01-003
- **Why**: The shadow keeps no store of its own (ADR-0190), so no database.db_url holds VINCE-derived records; SHD-01-003 forbids keeping any copy after its request
- **Last text**:

```yaml
  - id: VSD-01-001
    priority: MUST
    kind: project
    adr:
    - ADR-0189
    statement: >-
      In shadow mode, the server MUST store VINCE-derived records only in the
      store `database.db_url` names.
    rationale: >-
      One configured store is one place to protect, back up and delete. A second
      store, or a fallback, is a place nobody planned for.
    verification: >-
      A shadow run test (#5958) with `database.db_url` set to a path outside the
      checkout asserts the VINCE-derived records are written there and nowhere
      else.
```
