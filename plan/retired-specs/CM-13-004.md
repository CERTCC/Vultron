# CM-13-004 (retired)

- **Retired**: 2026-10-08 (#4292)
- **Replacement**: MSM-07-008
- **Why**: ADR-0122 rev 2 retires the two-audience rule: the case owner's decision for the case is Accept(EmbargoEvent, target=Case) (MSM-07-008), and Accept(Invite(EmbargoEvent)) is always the sender's own consent (MSM-07-003), so no handler branches on whether the sender is the owner. The ownerless-case fallback was never implemented (is_case_owner answers False for a case with no owner) and would let a non-owner make the owner's decision.
- **Last text**:

```yaml
  - id: CM-13-004
    priority: MUST
    kind: protocol
    statement: If `VulnerabilityCase.attributed_to` is `None` (legacy or single-actor case), the handler MUST treat the triggering
      actor as the case owner for the purposes of EM state transitions
    rationale: Backward compatibility with cases created before the `attributed_to` field was introduced; prevents single-actor
      embargo triggers from silently failing
    verification: A unit test confirms that when `VulnerabilityCase.attributed_to` is `None`,

      transitions.
```
