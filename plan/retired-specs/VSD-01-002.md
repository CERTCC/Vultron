- **Why**: The shadow hosts no server with a store to validate at startup (ADR-0190); SHD-02-001 gives its container no persistent volume
- **Last text**:

```yaml
  - id: VSD-01-002
    priority: MUST
    kind: project
    adr:
    - ADR-0189
    statement: >-
      In shadow mode, the server MUST refuse to start when `database.db_url` is
      the default, in memory, or inside the repository checkout.
    rationale: >-
      The default path is relative, so a server started from the checkout writes
      inside it, where an agent or a commit can pick up a case. Refusing to
      start cannot write a case to the wrong place.
    verification: >-
      A startup test (#5958) sets the default, an in-memory store, and SQLite
      paths inside the checkout (relative and through a symlink), and asserts
      each refuses to start with an error naming the setting.
```
