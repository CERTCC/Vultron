# ARCH-17-001 (retired)

- **Retired**: 2026-11-03 (#5339)
- **Why**: Names the ASGIEmitter, which ADR-0042 removed; no code depends on it and OX-12 governs delivery.
- **Last text**:

```yaml
  - id: ARCH-17-001
    priority: MUST
    kind: project
    verification_debt: '#2575'
    statement: >-
      The `ASGIEmitter` base URL MUST hold only the scheme and netloc components (e.g.
      `https://example.org`), with no path prefix, trailing slash or mount-point segment.
    rationale: >-
      The emitter strips the mount prefix from request paths before it builds outbound
      URLs, so a prefix in the base URL is applied twice.
      A base URL with a path prefix, such as `https://example.org/api`, joined with a
      request path such as `/api/actors/…`, gives
      `https://example.org/api/api/actors/…`, which is an address that does not exist.
      The `ASGIEmitter` is removed (ADR-0042), so no code now depends on this
      requirement (see the group description).
```
