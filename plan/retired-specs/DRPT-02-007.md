# DRPT-02-007 (retired)

- **Retired**: 2026-11-02 (#5351)
- **Why**: It requires `build_timeline` to skip ledger entries whose `disposition` is not `"recorded"`, but `CaseLedgerEntry` has no `disposition` field and `build_timeline` in `vultron/demo/report.py` filters on none: every replica entry is a canonical case event (CLP-02-004). Inclusion, de-duplication and order of entries are already covered by DRPT-02-004, DRPT-02-015 and DRPT-02-005, so no replacement is needed.
- **Last text**:

```yaml
  - id: DRPT-02-007
    priority: MUST
    kind: project
    verification_debt: '#2573'
    statement: >-
      `build_timeline` MUST skip entries whose `disposition` field is not
      `"recorded"` (e.g. `"rejected"`). Rejected entries are local-only
      correlation markers with empty `payloadSnapshot` values; including them
      in the report produces `—` actor labels and empty target columns that
      violate the CLP spec and mislead readers.
    rationale: >-
      An entry that the ledger did not record is not a case event. It has no actor and
      no target in its snapshot. If the report shows it, the report shows `—` labels
      and empty columns, and a reader can think that the case history contains an event
      that it does not contain.
    relationships:
    - rel_type: refines
      spec_id: DRPT-02-004
```
