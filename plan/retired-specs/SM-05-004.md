# SM-05-004 (retired)

- **Retired**: 2026-11-03 (#5469)
- **Why**: By design case_statuses holds full CaseStatus objects and ledger entries carry payload snapshots, so a reference-only state log is not the design.
- **Last text**:

```yaml
  - id: SM-05-004
    priority: SHOULD
    kind: architecture
    statement: The case state log SHOULD store references (IDs) to entries in the main case history log rather than duplicating
      full record content
    rationale: >-
      When a status record is stored in full in two logs, the two copies can differ
      after one of them changes. A reference by ID keeps one copy of the record, so the
      state log and the history log cannot disagree.
```
