# CLP-07-008 (retired)

- **Retired**: 2026-10-21 (#3742)
- **Replacement**: CLP-07-006
- **Why**: ADR-0107 records a received activity's body verbatim, so the CASE_MANAGER no longer resolves a nested reference from its store to inline it into a payloadSnapshot; CLP-07-006 forbids that resolution, which leaves no canonicalization path for this check to guard.
- **Last text**:

```yaml
  - id: CLP-07-008
    priority: MUST
    kind: project
    verification_debt: '#2575'
    statement: If a canonicalization path resolves an ID-string nested reference for
      `payloadSnapshot` inlining, it MUST verify that the resolved object's context
      matches the parent snapshot context before replacement. On context mismatch,
      the entry MUST be rejected rather than inlining cross-case data.
    rationale: Blind `dl.read(id)` replacement can leak unrelated local objects into
      canonical snapshots when inbound activities carry attacker-controlled IDs.
```
