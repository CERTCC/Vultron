  - id: CM-12-003

    statement: >-
      When a case is created from an `Offer(VulnerabilityReport)`, the Case Owner (the
      report receiver) MUST queue a `Create(VulnerabilityCase)` activity to notify the
      reporter that a case has been opened, naming the CASE_MANAGER it delegated to
      (CBT-01-001)
    rationale: >-
      The reporter must learn that its report became a case, and which actor coordinates
      the case. The reporter does not know the CASE_MANAGER. It trusts only the actor
      that it reported to. Thus the report receiver introduces the CASE_MANAGER to the
      reporter (CBT-01-001, ADR-0132).
    adr:
    - ADR-0132
    verification: >-
      Integration tests in `test/demo/` confirm that a `Create(VulnerabilityCase)`
      activity is queued for the reporter when a case is created from an
      `Offer(VulnerabilityReport)`.
