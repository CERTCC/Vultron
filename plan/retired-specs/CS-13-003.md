# CS-13-003 (retired)

- **Retired**: 2026-10-30 (#5452)
- **Replacement**: CS-13-007
- **Why**: Whole-second storage lost the order of acts inside one second; the fixed six-digit form keeps one string per instant without that cost (ADR-0167).
- **Last text**:

```yaml
  - id: CS-13-003
    priority: SHOULD
    kind: architecture
    statement: All datetime values SHOULD be stored at second precision (microseconds set to zero)
    rationale: >-
      A value with microseconds serializes with a fractional second, and a value
      without them does not. Two stores or peers can then hold different strings for
      the same instant, and an exact comparison fails. `now_utc()` drops microseconds,
      so every time the application creates has one form.
```
