# CM-13-003 (retired)

- **Retired**: 2026-10-08 (#4292)
- **Replacement**: MSM-07-003
- **Why**: ADR-0122 rev 2 retires the two-audience rule: the case owner's decision for the case is Accept(EmbargoEvent, target=Case) (MSM-07-008), and Accept(Invite(EmbargoEvent)) is always the sender's own consent (MSM-07-003), so no handler branches on whether the sender is the owner.
- **Last text**:

```yaml
  - id: CM-13-003
    priority: MUST
    kind: protocol
    statement: If the accepting actor is NOT the case owner, the handler MUST update only that participant's own consent
      row for the accepted embargo to `ACCEPTED`; it MUST NOT advance the shared EM state
    rationale: Non-owner participants do not hold a pocket veto; their individual acceptance does not constitute case-level
      embargo activation
    verification: Integration tests in `test/demo/` confirm that an embargo-accept from a
      non-owner participant updates only that participant's consent row for the accepted
      embargo to `ACCEPTED` without touching `CaseStatus.em_state`.
    stories:
    - story_2022_023
    - story_2022_027
```
