# RSH-05-023 (retired)

- **Retired**: 2026-10-20 (#3741)
- **Replacement**: RSH-09-005
- **Why**: ADR-0107 detail 5: a received status is accepted whole or refused whole, so the ledger never records a status nobody sent (#4451 decision on #3741). The EM acceptance rule moved unchanged into the whole-status rule.
- **Last text**:

```yaml
  - id: RSH-05-023
    priority: MUST
    kind: project
    statement: >
      When adjudicating the EM dimension of a received `Add(CaseStatus)`, the
      receiver MUST accept the asserted EM state only when it is identical to
      the case's EM state derived from its embargo register, and MUST refuse
      any other asserted EM value, carrying the case's value forward
      (RSH-05-016).
    rationale: >
      EM is derived from the case's embargo register, which changes only
      through the embargo messages that cause each register step (ADR-0122).
      A status can report EM but never move it: adopting an asserted EM would
      make the status copy disagree with the register it is derived from.
    verification: >
      Unit tests in `test/core/behaviors/status/test_add_case_status_bt.py`
      confirm that `FilterCsEmDimensionNode` passes an EM identical to the
      case's and refuses every other asserted EM value by carrying the
      case's value forward;
      `test/core/behaviors/sync/nodes/test_case_status_effect.py` confirms
      the same of `ApplyCaseStatusFromLedgerNode`.
    note: >
      The predicate is `is_em_assertion_acceptable(current_em, asserted_em)` in
      `vultron/core/states/em.py`, which accepts only `asserted == current`.
      Two nodes apply it, so the CASE_MANAGER and its replicas adjudicate EM
      alike: `FilterCsEmDimensionNode` in
      `vultron/core/behaviors/status/nodes/cs_dimension_filter.py` on a
      received `Add(CaseStatus)`, comparing with `VulnerabilityCase.em_state`,
      and `ApplyCaseStatusFromLedgerNode` in
      `vultron/core/behaviors/sync/nodes/case_status_effect.py` on the
      `add_case_status_to_case` ledger entry (RSH-08-004).
    adr:
    - ADR-0122
```
