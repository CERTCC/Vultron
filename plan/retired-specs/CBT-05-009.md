# CBT-05-009 (retired)

- **Retired**: 2026-11-02 (#5470)
- **Replacement**: CBT-05-008
- **Why**: CBT-01-007 now requires each bootstrap participant inline (ADR-0170), so a participant named only by URI is absent under CBT-05-008 for every implementation, and this codebase's rule that treats it as absent says nothing CBT-05-008 does not.
- **Last text**:

```yaml
  - id: CBT-05-009
    priority: MUST
    kind: project
    statement: >-
      This codebase MUST treat a participant that arrives in a bootstrap
      `Create(VulnerabilityCase)` as a bare URI reference as absent, and so
      MUST reject the bootstrap under CBT-05-008.
    rationale: >-
      CBT-05-008 states only what other participants observe; this item states
      how this codebase meets it (MS-12-010). This codebase fetches only the
      objects the note on AKM-05-007 lists, and a bootstrap participant is not
      one of them, so it cannot read a participant record named only by URI.
      Refusing it is a shortcut of this prototype reference implementation, not
      a protocol rule: an implementation that fetches the reference has the
      participant data and need not refuse it.
    verification: >-
      `test/core/use_cases/received/case/test_helpers.py::test_bootstrap_bare_uri_participant_is_refused`
      confirms a bootstrap with a bare-URI participant is refused with a reason
      citing CBT-05-008 before any DataLayer write.
    relationships:
    - rel_type: implements
      spec_id: CBT-05-008
```
