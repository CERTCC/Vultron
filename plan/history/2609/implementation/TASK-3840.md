## Task (#3840)

Rewrite the spec requirements that still mandated the cancelled `WireParsePort`
and the adapter-side translators ADR-0082 had planned, now that ADR-0099 is
`accepted` and ADR-0017 / ADR-0082 are retired in full (#3492).

Governing specs: MS-09-001 MS-09-002 MS-09-003 MS-14-005 ARCH-20-008
ARCH-20-009 SDO-04-001 CM-18-015 UCORG-05-014 AF-01-005.

## Requirement removed (MS-09-001, MS-09-002)

**SDO-04-001** (`specs/status-dimension-objects.yaml`, group SDO-04 "Wire
Projection and Migration Scope", priority MUST, kind protocol, stories
`story_2022_062` / `story_2022_088`, adr ADR-0036 / ADR-0082).

Statement as removed: "The wire-layer shapes `as_CaseStatus` and
`as_ParticipantStatus`, and the adapter-side translators that pair them with
their core counterparts, MUST be updated in the same implementation as the core
model changes so that translation in both directions correctly handles the
dimension-object field shape."

Why removed rather than rewritten: ADR-0099 detail 3 aliased `as_CaseStatus`
and `as_ParticipantStatus` onto the core classes and deleted the paired wire
classes with their `from_core()` / `to_core()`. With one class there is no
second shape and no translator whose update could lag the model, so the
obligation has no subject left. The invariant it protected — the AS2 form and
the core model never disagree — is carried by ARCH-12-003 (the `by_alias` dump
*is* the AS2 form, `extra="forbid"` refuses stale flat keys), SDO-03-005 (no
per-class reject-guard) and ARCH-23-005 (serialize-then-validate round trip).

Cross-references (MS-09-003): none in `specs/`, `docs/`, `notes/` or `test/`
pointed at SDO-04-001; SDO-04-002 and SDO-04-003 remain. Replacement pointers
for a reader arriving from the old ID: ARCH-12-003, SDO-03-005, ARCH-23-005.

## Requirements rewritten in the same change

ARCH-20-008, ARCH-20-009 (`rehydrate()` and `project_wire_snapshot_to_core`
replace the parse port), CM-18-015 (computed field, not a translator),
UCORG-05-014 (`ActivityResult` stays in `vultron/demo/` because
`as_TransitiveActivity` is wire-only), AF-01-005 (factories accept the domain
object; imports governed by the ARCH-22-001 allow-list). Each now derives from
ADR-0099. Three dead `getattr(obj, "to_core", None)` sites in `vultron/core/`
were removed and `test/architecture/test_core_no_to_core_duck_typing.py`
ratchets ARCH-20-008.
