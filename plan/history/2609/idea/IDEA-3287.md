## Summary

Expand the open-questions include-file pattern established in #3285 to cover open questions found elsewhere in the docs and notes — including those surfaced in PR #3265 and any others identified during content review.

## Motivation

Issue #3285 creates seven `_oq_*.md` fragment files from `notes/federation_ideas.md` and a collection page. The same pattern should be applied to open questions scattered in other content areas (other notes files, ADR open questions, protocol spec gaps). Centralising them in `docs/topics/future_work/open_questions.md` via include-markdown fragments gives readers one place to see what is unresolved.

## Scope

- Audit existing docs and notes for open questions sections
- Create `_oq_*.md` fragment files for each (or for natural groupings)
- Slot fragments into context pages via `include-markdown` admonitions
- Add fragments to the `open_questions.md` collection page
- Include additions from PR #3265
