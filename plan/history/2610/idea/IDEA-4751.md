## Summary

Add one cross-tab lookup page that lists every `page_type: reference` page (Protocol Specification, Protocol/Foundation requirement tiers, messages, glossary, conformance matrix, quick reference, and so on), generated from frontmatter and linked from the home page.

## Motivation

ADR-0102 rejected a reader-organized top level partly because it "discards a taxonomy that works for authors and for returning readers who already know what they want." Once Reference stops being a tab, returning readers lose the view by type. The PR #4681 review settled that a single generated lookup page brings that view back without bringing back the type-based top level.

## Rough Approach

- Generate the listing from `page_type: reference` (depends on #4683), grouped by tab or by subject, with each page's `description:`.
- Gate it with a `--check` mode like the other generated pages (DF-11-005), so it can't fall out of date.
- Link it from the home page and from each tab landing page.
