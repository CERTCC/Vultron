PR: <https://github.com/CERTCC/Vultron/pull/4277>

Full suite in a 2-CPU, 6 GiB worktree slot: ~19 min serial -> 7m14s.

- `-n auto` everywhere a gate runs the suite (skills, AGENTS.md, CI), with
  `pytest_xdist_auto_num_workers` in `test/conftest.py` sizing it from the
  cgroup CPU quota and memory limit (`test/support/xdist_workers.py`), since
  `nproc` reports every host core and 10 workers were OOM-killed.
- OX-13-013: a sealed body the outbox refuses (no recipient, non-inline
  object) is dead-lettered on the first refusal instead of spending the
  12-attempt budget on 1s/2s/4s backoff (~24s per row).
- `trigger/create-case` with no `to` no longer queues its `Create` (OX-08-001);
  every `setup_initialized_case` scenario had been producing one.
- `_no_outbox_row_is_dead_lettered` fails any demo test that dead-letters a row.
