PR #4830 closes issue #4646.

Changed SenderRule from in_case(PARTICIPANT) to to_case_manager(PARTICIPANT) on
OfferActorToCaseReceivedUseCase and AddParticipantStatusToParticipantReceivedUseCase.
A participant replica previously admitted these messages from any listed participant;
now only the CASE_MANAGER is admitted at a replica (PCR-03-001).

Added two @pytest.mark.spec("PCR-03-001") tests (each parametrized over both use
cases): test_replica_refuses_listed_non_manager_for_case_update and
test_replica_admits_case_manager_for_case_update.

msm-occasions --write: no "Sent by" changes (rule's CASE_MANAGER side unchanged).
